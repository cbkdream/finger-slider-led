출장 중이어서 아두이노 보드가 없어 출력 원리를 소프트웨어적으로 시뮬레이션했습니다. LED는 p5 화면 안의 가상 LED로 구현했고, 아두이노 코드와 회로는 Wokwi에서 확인했습니다.

시연 영상

1. 개요

웹캠으로 손을 인식해서 엄지와 검지 사이 거리로 슬라이더 값을 바꾸고, 그 값으로 LED 밝기를 조절했습니다. 슬라이더 값(0~255)에 따라 화면 가운데 가상 LED의 투명도(alpha)와 크기가 바뀌고, 아래쪽에 PWM 파형과 시리얼 송수신 내용이 표시됩니다.

웹캠 → HandPose(점 21개) → 중지 접었는지 확인 → 엄지-검지 거리 계산
     → 슬라이더(0~255) → "B:값" 전송 → 아두이노(가상) → LED 밝기

사용 방법

  • 데모 페이지를 Chrome으로 열고 카메라 권한을 허용합니다.
  • 중지를 접은 상태에서 엄지와 검지를 벌리면 밝아지고, 오므리면 어두워집니다.
  • 중지를 펴면 값이 고정됩니다. (마우스로 슬라이더 조절 가능)
  • C 키: LED 색 변경, S 키: 화면 저장

2. 구현 내용

손 인식

ml5.handPose()로 모델을 불러오고 detectStart(video, gotHands)로 인식을 시작했습니다. 사용한 점은 손목(0), 엄지 끝(4), 검지 끝(8), 중지 뿌리(9), 중지 끝(12)입니다.

주먹 모드

손목~중지 끝 거리가 손바닥 길이(손목~중지 뿌리)보다 짧으면 중지를 접은 것으로 보고, 이때만 슬라이더를 움직입니다.

거리 → LED 값

엄지-검지 거리를 손바닥 길이로 나눠 비율로 만들었습니다. 카메라와의 거리가 달라도 같은 손 모양이면 비슷한 값이 나옵니다.

let s = round(100 * (v / p)) - 15;      // v: 엄지-검지, p: 손바닥
s = constrain(s, 0, 100);
return round(map(s, 0, 100, 0, 255));   // LED 값 0~255

슬라이더 움직임 보정

떨림을 줄이려고 목표값과의 차이 중 20%씩만 움직이게 했는데, 슬라이더가 정수 단위라 목표 근처에서 멈추는 문제가 있었습니다(50 → 90일 때 88에서 멈춤). 차이가 3보다 작으면 바로 목표값으로 맞추도록 했습니다.

let next = c + 0.2 * (v - c);
if (abs(v - c) < 3) next = v;
slider.value(next);

가상 시리얼 / 가상 아두이노

슬라이더 값을 바로 LED에 쓰지 않고 "B:값" 문자열을 만들어 virtualArduino()에 넘기고, 이 함수가 LED 값을 정한 뒤 "PWM:값"을 돌려줍니다. Wokwi 아두이노 코드와 같은 형식입니다. 값이 바뀔 때만, 50ms 간격으로 보내도록 했습니다.

가상 LED

꺼진 회색 LED를 먼저 그리고, 그 위에 fill(r, g, b, 값)으로 색을 겹쳐 그렸습니다. 크기와 빛 번짐도 값에 따라 커집니다.

3. Wokwi 회로

D9 ── 220Ω ── LED(+)    LED(-) ── GND

시리얼로 한 줄씩 받아서 B:값 형식이면 analogWrite(9, 값)을 하고 PWM:값을 출력합니다. 시리얼 모니터에 B:0, B:64, B:255를 입력해 LED 밝기가 바뀌는 것을 확인했습니다.

void handleLine(const char *line) {
  if (line[0] != 'B' || line[1] != ':') return;
  int value = constrain(atoi(line + 2), 0, 255);
  analogWrite(LED_PIN, value);
  Serial.print("PWM:");
  Serial.println(value);
}

4. 고찰

  • 손이 조금만 흔들려도 LED가 깜빡거렸는데 20%씩 움직이게 하니 부드러워졌습니다. 대신 정수 반올림 때문에 목표값에 못 가는 문제를 따로 처리해야 했습니다.
  • 거리를 손바닥 길이로 나누는 방법 덕분에 카메라와의 거리가 달라도 값이 크게 바뀌지 않았습니다. 다만 손을 기울이면 값이 올라갔습니다.
  • 보드 없이 가상으로 만들었지만 문자열로 보내고 받는 과정을 거치게 해서, 보드가 생기면 전송 부분만 바꾸면 되도록 했습니다.
  • PWM 파형을 같이 그려 보니 LED 밝기가 켜져 있는 시간의 비율이라는 것을 이해하기 쉬웠습니다.
  • 개선할 점: 양손으로 LED 두 개를 따로 조절하기, 어두운 곳에서 인식이 불안정할 때 값을 바꾸지 않게 하기.
